# IMDB Movie Scraper

## Project Overview
IMDB Movie Scraper is a web scraping project that extracts movie details from IMDB using Python. The collected movie data is stored in CSV format and displayed through a Flask web application.

## Features
- Scrape movie details from IMDB
- Store extracted data in CSV files
- Display movie information using Flask
- Simple web interface

## Technologies Used
- Python
- Flask
- Selenium
- HTML
- CSS
- Pandas
